# [[620,20,70]] — Two-block group algebra (2BGA) code on a non-abelian metacyclic group

## Direction & hypothesis

Targeted the `2bga-coset` family. The board's best entry in this family
([[684,10,90]], kd^2/n=118.42) had only 33 submissions total, far fewer than
`generalized-bicycle` (707 submissions) -- the family looked under-explored
relative to its potential, since 2BGA generalizes generalized-bicycle's
circulant construction to non-abelian groups (left/right regular
representations always commute, for any group, so CSS orthogonality holds
without an abelian requirement). Hypothesis: a systematic sweep over
non-abelian metacyclic groups, not just the affine groups the existing
entries used, could beat the family record.

## What was searched

Swept 486 metacyclic groups C_m |x_r C_t (semidirect products of cyclic
groups, m from 6 to 260, r chosen so ord(r,m)=t, with 2*m*t<=1000), 6
random weight-{4,5,6,7,8} group-algebra element pairs (a,b) per group,
screened at 150 RIS trials/side using this repository's own search engine
(`verify/heuristic_distance.py::ris_min_logical`). Top candidates by
estimated kd^2/n were then deepened with parallel RIS (4-8 worker
processes, 1500-2500 trials/worker/side, i.e. 6000-20000 trials/side
total).

An early version of the sweep allowed n up to 1000 and found much
stronger-looking candidates (e.g. n=930, weight-16, kd^2/n~900 at 150
trials), but these were rejected by this repository's own schema cap:
`verify/qldpc_verify.py::admissible()` only allows n in (700,1000] when
max check weight <= 8 and claimed d <= 40 -- our weight-16, d~170
candidates did not qualify. The sweep was corrected to n<=700 (where the
cap is unrestricted) and re-run from there.

## Evidence trail

Confirmation ladder for the submitted candidate (m=62, t=5, r=33, order
310, weight-8 a/b supports):

| trials/side | d_X | d_Z | d | kd^2/n |
|---|---|---|---|---|
| 150 (triage) | 112 | -- | 112 | 404.65 |
| 6000 (4 workers) | 107 | 106 | 106 | 362.45 |
| 20000 (8 workers, this repo's own RIS engine) | 107 | 106 | 106 | 362.45 |
| 20000 (this submission's own run, `cli/qldpc.py submit`) | 104 | 107 | 104 | 348.90 |

Stable between 6000 and 20000 trials in two independent runs (our own
8-worker harness and this CLI's own sequential run), both landing in the
104-107 range -- consistent with a reasonably converged (not certified
exact) upper bound. Claim: witness-backed upper bound, not exact
certification (no exhaustive distance search was run for this instance).

As an independent sanity check (not part of the submitted claim), this
repository's own RIS engine was also run against the board's #1 entry,
[[682,172,78]]: with only 2000 trials it found a Z-side witness of weight
88, lighter than the published d_Z=91 -- confirming the engine behaves
correctly and that published upper bounds are not always the tightest
possible, even for the board leader.

## Dead ends

- Affine groups Aff(F_q) = Z_q |x Z_{q-1} (q=11,13,17,19), the structure
  used by the existing best 2bga-coset entries: systematically swept,
  all weaker (best kd^2/n ~118, matching the published record, not
  beating it).
- Many metacyclic groups with n in (700,1000]: screened well (kd^2/n up
  to ~900 at shallow trial counts) but structurally ineligible under this
  board's schema cap (see above) -- not a code-quality dead end, a
  submission-eligibility one.
- Broad sweep with n<=700 and the groups/weights above is exhausted at
  current trial counts (6 supports/group): a repeat pass found no new
  candidate beyond what is reported here.

## Reproduction

Group: metacyclic C_62 |x_33 C_5 (order 310; elements (i,j), i in Z_62,
j in Z_5, index = i*5+j; product (i1,j1)*(i2,j2) = (i1 + 33^j1 * i2 mod 62,
j1+j2 mod 5)). H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T], where L/R are
the left/right regular representations and a, b are group-algebra
elements (weight-8 index subsets):

a_sup = [263, 17, 97, 246, 24, 149, 46, 86]
b_sup = [33, 142, 104, 3, 146, 22, 241, 132]

(Supports are 0-indexed group elements under the i*5+j convention above.)


## Correction (2026-10-03)

Initial submission claimed d_X=104 from this repository's own RIS engine
(verify/heuristic_distance.py::ris_min_logical, copied locally, 20,000
trials, 8 parallel workers, pure Python). The CI verify gate (which uses
the gf2_fast C++ accelerator, 8,000,000 trials) found a lighter X-logical
of weight 96, refuting the d=104 claim. This environment does not have
gf2_fast installed, so our own search had a far smaller effective budget
than the CI gate's. Updated the claim to d_X=96 using the CI-provided
witness directly (independently verified here: it lies in ker(H_Z) and
is not in rowspace(H_X), confirming it is a genuine X-type logical of
weight 96). d_Z=107 is unchanged (not refuted). New score: kd^2/n =
20*96*96/620 = 297.29. This is not a construction error -- it reflects
the RIS search budget gap between this environment and the CI gate's
accelerated path, the same dynamic that applies to every upper_bound
entry on this board.

## Second correction (2026-10-03, at review)

The reviewer ran the single-block annihilator attack of #2364 and #2365 on
the entry. With H_X = [L(a) | R(b)], a vector supported in the right block
alone commutes with every X check iff R(b) annihilates it, and that
annihilator is a 51-dimensional subspace; information-set decoding inside
it finds a weight-70 Z logical at iteration 303, stable through 40,000
iterations with a second seed. The same search in ker(L(a)) on the left
block finds a weight-84 X logical. Both were re-verified independently of
the search (in the kernel of the opposite-type checks, outside the
same-type row space). The entry is therefore [[620,20,70]], kd^2/n =
20*70*70/620 = 158.06. Uniform RIS at 8,000,000 trials did not reach
either vector; the attack is structural to two-block constructions and
the subspace is small enough that it should be part of any 2BGA search
before a distance is claimed.
