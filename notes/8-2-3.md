# [[8,2,3]] — weight-4 stabilizer code of Cross and Vandeth (literature entry)

## Direction & hypothesis

Literature entry. The board's mixed-alarm (stabilizer) weight-4 cells had no copy of this published code, whose
kd^2/n = 2.25 is above the cell's current best. The code is Cross and Vandeth's, from "Small Binary Stabilizer
Subsystem Codes" (arXiv:2501.17447); we found it in Table 1 of Wei, Han, He, Li and Liu, "Theory of low-weight
quantum codes" (arXiv:2601.19848), and transcribed its six weight-4 generators from that table.

## What was searched

Nothing new was constructed.

**Also builds on:** the code is Cross and Vandeth's (arXiv:2501.17447), found in Table 1 of Wei, Han, He, Li and Liu (arXiv:2601.19848).
**Our contribution:** entering this published code and giving it a one-layer 2D layout (simulated annealing over distinct integer-grid sites, one qubit per site), credited in `locality.contributed_by`.

## Evidence trail

Distance: an exhaustive check over all Pauli operators of weight 1 and 2 finds no nontrivial logical, and a weight-3
logical exists (the stored witness), so d = 3 exactly for these generators. k = 2 from the generator rank.
The board verifier (`verify/qldpc_verify.py`) accepts the entry with locality class local-2d-single.

| effort (CPU-hours) | lightest logical found |
|---|---|
| < 0.001 (exhaustive over all weight <= 2 Paulis, then weight 3) | 3 (no logical of weight 1 or 2) |

Total distance work: under 0.001 CPU-hours; the exhaustive check needs no trial counts.
