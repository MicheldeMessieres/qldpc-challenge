# [[48,4,4]] — exact non-CSS perturbed bivariate bicycle (PBB) code

**Paper:** arXiv:2610.06623, "Large Language Model-Guided Discovery of
Weight-Five Bivariate Bicycle Codes" (component of presentation `PL-78c3e7bf`).

## Direction & hypothesis

Target: the general-stabilizer board's `unrestricted` x `weight-6` (and
looser) cells. Same PBB construction family as the companion `[[144,12,12]]`,
`[[216,4,10]]`, `[[12,2,3]]`, `[[144,4,8]]`, `[[180,2,11]]`, `[[360,4,12]]`,
`[[360,12,20]]`, and `[[360,4,24]]` submissions in this batch (block-1 z-part
`[C | D]` added to a CSS bivariate-bicycle stabilizer matrix:
`H = (A B | C D; 0 0 | B^T A^T)`).

## What was searched

Source: a weight-5-targeted LLM-guided evolutionary search (OpenEvolve,
"pbb-large" campaign) over 4-tuples `(A, B, C, D)` at `(ell=12, m=12)`,
screened by `k`, isotropy, the combined non-CSS gate
(`evaluation/noncss_gate.py`), and a BP-OSD distance estimate. The surviving
presentation `PL-78c3e7bf` (`n=288, k=24`) is a direct sum of 6 isomorphic
components (`evaluation/connectivity.py:stabilizer_components` +
`components_isomorphic`, confirmed homogeneous and BLISS-isomorphic); each
component is `[[48,4,4]]`, with the parent's exact MILP distance
(`results/weight5_publication_catalogue.jsonl`, `distance_class.status_code:
"E"`) transferring to each component.

Unlike the companion `[[144,4,8]]` and `[[180,2,11]]` submissions, no
standalone explicit presentation of this component already existed in the
source repository as its own clean `(ell', m')` pair. This submission builds
one directly: the parent presentation's symplectic matrix was constructed
via `evaluation/pbb_code.py:build_pbb_code(12, 12, ...)`, then restricted to
one component's qubit support via
`evaluation/connectivity.py:_induced_presentation_subcode` (the
generator-presentation-preserving induced restriction, not the row-echelon
one) — performed in this submission session, using only the source
repository's own, already-published tools.
