Target: the general-stabilizer board's `unrestricted` x `weight-6` (and
looser) cells. Same PBB construction family as the companion submissions in
this batch (block-1 z-part `[C | D]` added to a CSS bivariate-bicycle
stabilizer matrix: `H = (A B | C D; 0 0 | B^T A^T)`).

## What was searched

Source: a weight-5-targeted LLM-guided evolutionary search (OpenEvolve,
"pbb-large" campaign) over 4-tuples `(A, B, C, D)`, screened by `k`,
isotropy, the combined non-CSS gate (`evaluation/noncss_gate.py`), and a
BP-OSD distance estimate. The underlying code was first found as one of 2
isomorphic components of a disconnected parent presentation at
`(ell=15, m=12)`, `n=360, k=4`
(`evaluation/connectivity.py:stabilizer_components` + `components_isomorphic`);
the parent's exact MILP distance transfers to each component. A standalone,
explicit presentation of one component at its native `(ell=15, m=6)` was
then independently constructed and certified
(`results/weight5_pbb_component_certifications.jsonl`, match
`W5PBB-180-2-11-8ee754a5`): re-run through the same non-CSS screens and
confirmed connected.
